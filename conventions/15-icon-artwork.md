# 15 · 图标画风与墨迹基准

**状态：草案（draft）** —— 画风数值从官方 `ui-primitives/src/icons` 实测反推，未经多插件并行实践验证。

图标是侧栏入口最容易「看着不齐但说不出哪不对」的部分：按钮几何再对，只要墨迹大小、笔画粗细、明暗层级不统一，一排入口仍然互相打架。本章补充 §10 只写了「16×16 / 18×18」两行数字漏掉的部分：**画布、描边、着色、墨迹盒**。

## 官方做法（源码反推，`@deepseek-ai/ui-primitives`）

| 项 | 值 | 位置 |
|---|---|---|
| 画布 | `viewBox="0 0 16 16"` | `icons/artwork.ts`，99 个 glyph 中 95 个 |
| 线重 | Regular `1.0` 用户单位 / Medium `1.3` | `artwork.ts:9` `ICON_REGULAR_STROKE`、`:12` `ICON_MEDIUM_STROKE` |
| 端点 | `linecap`/`linejoin` 均为 `round` | 同文件 |
| 着色 | **只用 `currentColor`**，fill/stroke 都不写死颜色 | 全部 glyph |
| 尺寸 | 不是组件名的一部分，是 `size` prop，默认取 glyph 自绘尺寸 | `props.ts`、`index.tsx` |
| 侧栏入口 | 文字态 `16px` / 图标态 `18px`（`size={wide ? 16 : 18}`） | `ui-settings-general` `chrome.tsx`、`ui-cordis` `CordisPanel.tsx` 两处独立一致 |

> 图标名不带画板尺寸、以 `Regular`/`Medium` 结尾；`size` 控制渲染尺寸，描边随视口缩放
> （16 单位 viewBox 中 1 单位描边在 18px 下 ≈ 1.125 CSS px）。「颜色继承 currentColor」由
> `<use>` 引用 sprite 时自动成立，插件别在 CSS 里再盖一层。

## 墨迹盒（MUST）

**判据是渲染后的墨迹，不是传进去的 `size`。** `size=18` 只保证 SVG 盒子 18px，不保证图形本身
看起来是 18px——画布留白决定了后一半。官方 16-viewBox 图标的墨迹普遍填到 14~15 单位（四周留
0.5~2 单位），据此：

| 渲染尺寸 | 墨迹盒 `max(w, h)` |
|---|---|
| 图标态 `18px` | `[13.5, 17]px` |
| 文字态 `16px` | `[12, 15]px` |

允许 ±0.5px 容差；**低于下限 = 图标显小**（画布留白过多），**高于上限 = 图标显胀**（几乎撑满，
和 12px 圆角的按钮不协调）。

### 测量方法

截图或渲染后取图形所在像素，外接盒（exclude 掉透明 padding）：

- 墨迹 = 非背景像素的外接盒边长，用 `max(w, h)` 判定
- 中心 = 墨迹盒中心与按钮盒中心偏差应 ≤ `0.5px`
- 同排一致性：相邻入口的墨迹覆盖率（墨迹像素 ÷ 墨迹盒面积）差 ≤ `15` 个百分点

## 同排一致性（SHOULD）

| 项 | 建议 |
|---|---|
| 墨迹盒 | 相邻入口 `max(w,h)` 差 ≤ `2px` |
| 笔画 | 描边风格一致（线型对线型、填充对填充），同一排不混用 |
| 明暗 | 同级入口用同一 `label` token；不要一个 `label-primary` 一个 `label-secondary` |

## 品牌 logo 例外（允许，但有三个门槛）

有自己的图形资产（吉祥物、产品 logo、既有品牌 mark）时，允许任意 `viewBox` 与填充路径：

1. 图标态仍按 `18px` 渲染（不要在 36×36 按钮里比别的入口大）
2. **墨迹盒仍落在 `[13.5, 17]px`**——logo 的留白要按这个重排
3. 单色 `currentColor`（不得依赖内嵌调色板；需要品牌色时由宿主 token 提供，插件不写死）

> 兼容案例：`dsh-chat-import` 的 logo 是 `viewBox="0 0 1024 1024"` 的双路径填充图形，渲染 18px 没错，
> 实测墨迹 16×16 也落在区间内；但 1024 网格缩到 18px 后细节容易发糊，重绘时优先回到 16 或 24 网格，
> 保留原资产则按本节三个门槛验收。

## 嵌入式图标该避开什么

- ❌ `fill="#…"` / `stroke="#…"` 写死颜色——hover/active 变色时图标不跟着变
- ❌ 自带背景块（圆底、方底）——36×36 按钮已经有自己的底色和圆角
- ❌ 渐变 / 多色——和同排单色描边图标不是一个语言
- ❌ 用 `width/height` 属性而不是 `size` 控制尺寸——没法跟随「文字态 16 / 图标态 18」切换
- ❌ SVG 里留白超过 50%（图形只占 viewBox 一小角）

## 自检清单

- [ ] `viewBox="0 0 16 16"`（或品牌 logo 例外条款下的任意 viewBox）
- [ ] 图标态按 `18px` 渲染、文字态按 `16px`
- [ ] 墨迹盒 `max(w,h)` 落在 `[13.5, 17]px`（图标态）
- [ ] 只用 `currentColor`，无 hex、无渐变、无自带背景
- [ ] 中心与按钮盒中心偏差 ≤ `0.5px`
- [ ] 与相邻入口的墨迹覆盖率差 ≤ `15` 个百分点
